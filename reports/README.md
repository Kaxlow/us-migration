# Reports

This directory contains written findings and generated analysis outputs:

- [EDA summary](eda_summary.md): acquisition integrity, coverage, data quality,
  and selected migration associations, generated by `scripts/audit_data.py`.
- [Chart gallery](eda_visualizations.md): ten captioned findings charts generated
  by `notebooks/02_eda_findings.ipynb`.
- `figures/cleaning/`: raw-versus-cleaned comparisons and cleaned-table examples.
- `figures/eda/`: the ten findings charts, exported as PNGs.
- `tables/`: CSV diagnostics, cohort validation and retention summaries, chart
  data, and correlation matrices with pair counts.

With raw snapshots and cleaning supplements available, regenerate the reports
from the repository root:

```powershell
python scripts/run_notebooks.py
python scripts/audit_data.py
```

The notebooks save their outputs and export figures and tables. The audit script
verifies active raw snapshots and refreshes the summary and coverage reports.
Generated figures are ignored by Git; Markdown reports and diagnostic CSVs are
reviewable project artifacts. Regeneration updates current outputs but does not
remove obsolete files left by earlier analyses.

See [the workflow](../docs/workflow.md) for setup and acquisition steps, and
[methodology](../docs/methodology.md) for interpretation limits.
